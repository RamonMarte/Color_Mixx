1. Introducción

En Color Mixx respetamos el derecho de los usuarios a conocer y controlar la información relacionada con el uso de nuestra aplicación.

Esta página explica los procedimientos para eliminar los datos almacenados localmente en el dispositivo y proporciona información sobre los servicios externos utilizados por el videojuego.

2. Datos almacenados localmente

Color Mixx utiliza una base de datos SQLite para almacenar información necesaria para conservar el progreso de las partidas.

Entre los datos almacenados se encuentran:

  • Progreso del jugador.
  • Información del nivel alcanzado.
  • Intentos disponibles para mezclar bolas.
  • Intentos disponibles para agregar recipientes o ampliar su capacidad.

Estos datos se guardan localmente en el dispositivo donde se ejecuta la aplicación.

3. Cómo eliminar los datos de Color Mixx

Para eliminar el progreso y los intentos almacenados localmente, el usuario puede borrar los datos de la aplicación desde la configuración de Android.

Pasos para eliminar los datos

  1. Abre la aplicación Ajustes de tu teléfono.
  2. Busca y selecciona Aplicaciones.
  3. Localiza y abre Color Mixx.
  4. Accede a la opción Almacenamiento.
  5. Selecciona Borrar datos o Borrar almacenamiento.
  6. Confirma la operación cuando Android lo solicite.

Los nombres de las opciones pueden variar según el fabricante y la versión de Android.

También puedes desinstalar la aplicación desde tu dispositivo. Sin embargo, recomendamos utilizar la opción de borrar almacenamiento cuando quieras eliminar expresamente los datos locales de la aplicación.

Consulta la guía oficial de Android para borrar los datos de una aplicación.

4. Consecuencias de eliminar los datos

Al borrar el almacenamiento de Color Mixx, Android elimina permanentemente los datos locales de la aplicación.

Esto puede provocar:

  • Pérdida del progreso guardado.
  • Pérdida del nivel alcanzado.
  • Restablecimiento de los intentos almacenados localmente al iniciar una nueva partida.

Esta operación puede ser irreversible. Por eso recomendamos asegurarte de que deseas eliminar los datos antes de confirmar la acción.

5. Información relacionada con la publicidad

Color Mixx integra Google AdMob para proporcionar anuncios dentro del juego.

El SDK publicitario puede procesar determinadas categorías de información, como identificadores, interacciones y datos técnicos del dispositivo, de acuerdo con su funcionamiento y configuración.

Borrar el almacenamiento local de Color Mixx no significa que se elimine automáticamente toda la información que Google u otros proveedores publicitarios puedan haber tratado.

Esa información se administra conforme a las políticas y herramientas de privacidad de los respectivos proveedores.

6. Opciones de privacidad de Google

Los usuarios pueden consultar y gestionar diferentes preferencias relacionadas con la información utilizada por Google para mostrar anuncios.

Google proporciona herramientas para administrar los datos utilizados para personalizar la publicidad.

Puedes acceder a:

  • Mi Centro de anuncios de Google.
  • Información sobre el control de datos utilizados para publicidad.
  • Mi Actividad de Google.

Estas herramientas permiten gestionar determinadas preferencias y actividades de la cuenta de Google, pero no representan necesariamente una solicitud de eliminación de todos los datos publicitarios tratados por los diferentes servicios.

7. Cuentas de usuario

El procedimiento descrito en esta página se refiere al progreso y los intentos almacenados localmente en Color Mixx.

Si una versión futura incorpora registro o creación de cuentas de usuario, se habilitará un procedimiento específico para solicitar la eliminación de dichas cuentas y de los datos asociados.

Cuando una aplicación permite crear cuentas, Google Play exige ofrecer mecanismos accesibles para solicitar su eliminación, tanto dentro de la aplicación como mediante un recurso web.

Puedes consultar los requisitos en la documentación oficial de eliminación de cuentas de Google Play.

8. Consultas y solicitudes

Para consultas relacionadas con el almacenamiento local, el tratamiento de información o la eliminación de datos, puedes comunicarte con el desarrollador.

Las solicitudes relacionadas con servicios externos, como Google AdMob, deben gestionarse mediante los canales y herramientas proporcionados por dichos servicios.
